## App Store privacy note (for the app owner)

"Data Not Collected" matches the app as implemented on 2026-11-10: no account, ads, analytics, tracking SDKs, developer server or IAP; photos are processed on device; only local photo identifiers and decisions are stored on the device. Re-check before submission if the app adds networking, SDKs, crash reporting or purchases. Answers in App Store Connect are entered by the owner, not from this repo.

This repository contains only the public website. App source code is not published here.
